# Kachumbari 🚖

Kachumbari is a scalable ride-hailing platform inspired by Uber and Bolt.

## Vision
To build a reliable, real-time transport and delivery system designed for modern cities.

## Project Status
🚧 Initial setup and architecture planning

## Planned Features
- Rider application
- Driver application
- Admin dashboard
- Real-time tracking
- Secure authentication
- Payments integration

## Tech Stack (Planned)
- Frontend: React
- Backend: Node.js / Laravel
- Database: PostgreSQL / MySQL
- Realtime: WebSockets
